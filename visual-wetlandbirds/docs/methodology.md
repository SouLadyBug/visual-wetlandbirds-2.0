# Methodology

## 1. Dataset audit

The pipeline validates file availability and basic schema assumptions, checks missing values and duplicates, evaluates malformed/tiny bounding-box annotations on a configurable sample, and performs cross-file video consistency checks.

## 2. Exploratory analysis

The analysis produces species and behavior class distributions, clip-length information, and official split counts. Additional figures can be added once the exact report requirements are available.

## 3. Crop classification

Two tasks are maintained separately:

- **Species classification:** a bird crop is mapped to a species label.
- **Behavior classification:** a crop sampled from a behavior clip is mapped to an action/behavior label.

The supplied project compares four ImageNet-pretrained CNNs using frozen backbones and a task-specific classifier head. The refactored pipeline retains that controlled benchmark scale and uses video-grouped stratification to reduce temporal/video leakage.

## 4. Statistical comparison

Each fold produces predictions for samples not used to train that fold. These out-of-fold predictions provide a common paired evaluation basis for model comparisons. McNemar's test is then applied pairwise, followed by Holm-Bonferroni correction within each task's family of comparisons.

## 5. Full-frame detection

Detection is treated as a separate problem from crop classification. Full frames contain one or more bird instances with species labels and bounding boxes. The supplied project uses Faster R-CNN with a MobileNetV2 feature backbone. The refactored pipeline preserves the architecture while enforcing video-level separation in holdout and cross-validation.

## 6. Literature comparison

The original source contains hardcoded YOLOv9 values as external literature metrics. These are not generated by this repository. A final paper comparison should explicitly identify the source, dataset release, split, preprocessing, detector implementation, confidence threshold, IoU thresholds, and AP definition before interpreting numerical differences.
