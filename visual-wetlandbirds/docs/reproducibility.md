# Reproducibility checklist

- [x] Central configuration.
- [x] Relative paths rather than machine-specific paths.
- [x] Explicit random seed.
- [x] Machine-readable outputs.
- [x] Run logging.
- [x] Unit tests for core parsing/statistics utilities.
- [ ] Dataset version recorded.
- [ ] Hardware/CUDA environment recorded for final runs.
- [ ] Exact paper protocol verified.
- [ ] Final classification grouping strategy verified.
- [ ] Final report supplied and reconciled with code.
